# Support policy

SSHScript 3.1 supports Python 3.11 through 3.14 on current Linux and macOS
systems. The latest 3.1.x release receives bug and security fixes. Support is
community-maintained and best effort; there is no guaranteed response time.

Use the following channels:

- [GitHub Discussions](https://github.com/iapyeh/sshscript/discussions) for
  usage questions and design discussions;
- [GitHub Issues](https://github.com/iapyeh/sshscript/issues) for reproducible
  defects and feature requests;
- [private vulnerability reporting](https://github.com/iapyeh/sshscript/security/advisories/new)
  for security issues.

A useful defect report includes the SSHScript, Python and Paramiko versions,
the operating system, the SSH server implementation, a minimal reproduction,
the expected result, and a redacted traceback. Do not post passwords, private
keys, internal hostnames, full private paths, or captured production output.

Site-specific deployment design, cross-distribution PAM policy, and third-party
server configuration are outside the maintenance commitment, although concise
reproductions and patches are welcome.
